# MD Studio — مواصفات استيراد ZIP والتنفيذ الحالي

## السلوك المعتمد
- يقبل مستورد المشاريع امتداد ZIP فقط. ملفات RAR و7z وtar.gz لا تُعامل كملفات ZIP.
- تتم قراءة الأرشيف من ملف مرحلي ثم قراءة جدول المحتويات قبل أي استخراج.
- يتم رفض المسارات المطلقة و`..` و`.` والرموز غير الآمنة، ومنع الخروج من مجلد الاستخراج.
- يتم اكتشاف الأسماء المكررة حرفيًا والمتعارضة باختلاف حالة الأحرف قبل الكتابة.
- يتم فحص أحجام الملفات ونسبة الضغط، مع حد أمان إجمالي 2 GiB للحجم المفكوك. هذا حد حماية للاستخراج وليس حدًا لحجم ملف ZIP المضغوط.
- يتم فك الضغط بالتدريج عبر buffer، وحساب SHA-256 لكل ملف، والتحقق من الحجم الفعلي مقابل الحجم المسجل في الأرشيف.
- يتم اكتشاف جذر Gradle تلقائيًا حتى عمق ثلاثة مجلدات، ويرفض الاختيار التلقائي إذا وجد أكثر من جذر.
- يحتفظ MD Studio بشجرة الاستيراد الأصلية في `files/imported-originals`، وينشئ نسخة عمل منفصلة في `files/projects`.
- التحليل البنيوي قراءة فقط. لا يتم إصلاح Gradle أو تعديل Manifest أو حذف مخرجات بناء أثناء الاستيراد.
- الملفات غير المعروفة والمخفية ومخرجات البناء القديمة وملفات التوقيع لا تُحذف من النسخة الأصلية.

## الملفات الإلزامية للتحقق الأولي
- `settings.gradle` أو `settings.gradle.kts`
- `build.gradle` أو `build.gradle.kts`
- `app/build.gradle` أو `app/build.gradle.kts`
- `app/src/main/AndroidManifest.xml`
- `gradle/wrapper/gradle-wrapper.properties`
- `gradlew` و`gradlew.bat`
- `gradle/wrapper/gradle-wrapper.jar`
- ملف Java أو Kotlin واحد على الأقل تحت `app/src/main`

## حالات الجاهزية
- `BLOCKED`: ملف إلزامي مفقود أو فشل تحقق بنيوي.
- `READY_WITH_WARNINGS`: البنية المطلوبة موجودة لكن توافق Gradle/AGP/Kotlin/SDK أو البناء الفعلي لم يُثبت بعد.
- `READY`: لا يصدر بمجرد الاستيراد؛ يتطلب استكمال فحوص التوافق والبناء والاختبارات الفعلية.
- `NOT_VERIFIED`: لم تتوفر أدلة كافية لتصنيف الحالة.

## حدود التنفيذ الحالي
- لا يوجد بعد محلل كامل لإصدارات AGP/Kotlin/JDK/SDK أو تحليل Imports/Classes/Functions/Compose.
- لا يوجد بعد إصلاح آلي لترميز أسماء ZIP القديمة؛ الأسماء غير القابلة للفك تحتاج معالجة منفصلة قبل اعتمادها.
- لا يوجد حتى الآن تقرير واجهة تفصيلي قابل للتنزيل لكل ملف، رغم حفظ SHA-256 في نتيجة الاستيراد داخل الذاكرة.
- لا يتم التحقق من صلاحية توقيع APK أو صحة مفاتيح التوقيع أثناء الاستيراد.
- وجود الملفات المطلوبة لا يعني أن المشروع قابل للبناء؛ يجب تشغيل Gradle في بيئة متوافقة.
